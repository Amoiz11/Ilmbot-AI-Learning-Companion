IlmBot 01 / Problem & Solution Analysis
EXECUTIVE SUMMARY

Addressing the Modern Learning Crisis

Students today are overwhelmed by fractured software workflows and generic AI that lacks academic context.

⚠️ The Current Student Dilemma
1. Fragmented App Overload Students juggle 5+ separate applications: Quizlet for flashcards, ChatGPT for general chat, StackOverflow for coding errors, and separate note-taking apps. Continuous context switching degrades focus and memory retention.
2. Zero Academic Memory & LaTeX Failure Generic chatbots fail to parse complex academic formulas, render garbled math symbols, and lack persistent conversation management categorized by academic subjects and topics.
3. Document & Handwritten Note Blindspot Standard LLMs cannot reliably ingest student lecture slides, textbook PDFs, or handwritten notes with image-level mathematical equations and diagrams without losing context.
4. No Bridge Between Theory & Code Computer Science and STEM students study programming theory alongside practical lab work, but existing platforms force them to use entirely separate tools for code debugging vs. exam revision.
💡 The IlmBot Unified Approach
1. All-in-One Educational Workspace Unifies conversational tutoring, live code execution assistance, auto-generated revision packs, and a document intelligence library into one cohesive, single-login dashboard.
2. KaTeX Math & Auto-Saved History Full LaTeX/KaTeX equation rendering guarantees pristine mathematical and scientific formulas. Chat sessions are auto-titled by LLM and archived in PostgreSQL for instant resumption.
3. Multimodal RAG with Gemini OCR Combines Gemini Vision OCR for handwritten notes and pypdf for textbooks with PostgreSQL pgvector embeddings, enabling students to query their exact course materials directly.
4. Dual Academic & Coding Personas Provides a dedicated Coding Coach alongside the general Learning Coach, equipped with language-aware prompts, syntax-highlighted solutions, and step-by-step logic breakdowns.
🎯
The IlmBot Value Proposition
By integrating generative intelligence with localized vector search and automated pedagogical tools (quizzes, flashcards, code coaching), IlmBot reduces study preparation time by 60% while dramatically improving retention.

IlmBot 02 / Core Feature Capabilities
FUNCTIONAL MODULES

Engineered for Holistic Learning

Four specialized micro-architectures working in harmony to support students at every stage of their academic journey.

🧠
Learning Coach (AI Tutor)
Multi-turn conversational tutoring powered by the Groq LLaMA 3.3 70B engine. Features native LaTeX/KaTeX math rendering for complex formulas, voice input via the browser Web Speech API, automatic conversation titling, and persistent multi-session memory stored in Neon PostgreSQL.
Multi-Turn Context KaTeX Math Voice Input Auto-Titling History Search
💻
Coding Coach (AI Mentor)
A dedicated programming environment with language-aware system prompts tailored for Python, C++, Java, JavaScript, and SQL. Provides structured error diagnostics, algorithmic complexity explanations (Big-O), code snippets with one-click clipboard copy, and iterative code refactoring.
Language Aware Debug Workflows Syntax Highlight One-Click Copy
📝
Smart Revision Engine
Instant pedagogical content generation on any subject. Generates Multiple Choice, True/False, and Short Answer quizzes with real-time scoring and detailed explanations. Includes an interactive 3D flip flashcard generator with keyboard navigation and complete client-side PDF export via jsPDF.
MCQ / T&F Quizzes 3D Flip Flashcards PDF Export Revision Packs
📄
Document Intelligence (RAG)
End-to-end Retrieval-Augmented Generation pipeline. Ingests PDFs and scanned image notes via Google Gemini Vision OCR. Extracted text is chunked into overlapping segments, vectorized via Google Text Embeddings, and indexed in PostgreSQL pgvector for cosine-similarity semantic search.
Gemini Vision OCR pgvector Search PDF Ingestion Semantic Chunking
🔐 Production Security & Identity: Google OAuth 2.0 with JWT verification, CORS policy protection, client-side image compression, and SSL/TLS encryption across all endpoints.
